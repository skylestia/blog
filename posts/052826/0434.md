# Microsoft has removed the sidebar from Edge

{:toc}

## Context

I learned some months ago that [Microsoft was planning to remove the sidebar from Microsoft Edge.](https://windowsreport.com/microsoft-to-retire-sidebar-app-list-in-edge-focuses-on-copilot/) This was a problem for me because the sidebar has been very important to my browsing habits and workflow for years, ever since Old Opera (versions 12 and prior) before they switched to Chromium. The sidebar had become so important to me that, when Opera did switch to Chromium, at first missing many of the features that made it stand out from other browsers, I started looking for other browsers. You can imagine that I immediately switched to Vivaldi when I first heard about it. I eventually left it for Edge for a number of reasons, but the primary reason I was willing to do so was that Microsoft had implemented a sidebar in it.

So, of course, I am aware of several browsers that have functional multitask-friendly sidebars, which is useful now as Microsoft is now removing the sidebar. While it was first announced months ago and has been planned for those months, many users are only just recently finding out as the ability to add new web panels was removed and, as of writing this, the sidebar itself is finally gone.

This has resulted in several posts on MS Edge related subreddits from users asking why it's removed and hoping to petition Microsoft not to remove it. I have commented on some of those posts to share other web browsers that still have sidebars in case other users would prefer to switch to an alternative. So that I don't spam those subreddits and so that my Reddit profile isn't the same long list over and over again, I've decided to post it elsewhere to have a single location to point people. Specifically, here.

Below is a list of those alternatives categorized by engine:

### Browsers
**Gecko:**
- [Floorp](https://floorp.app)

**Chromium:**
- [Vivaldi](https://vivaldi.com)
- [Naver Whale](https://whale.naver.com/en/)
- [Opera](https://www.opera.com/) (and all its [variants](https://www.opera.com/browsers))

**Qt-Webkit:**
- [Otter](https://github.com/OtterBrowser/otter-browser)

### Other solutions:
- [Firefox](https://www.firefox.com/en-US/) (and all its [other channels and variants](https://www.firefox.com/en-US/channel/desktop/)) - with [Second Sidebar](https://github.com/aminought/firefox-second-sidebar)
- [Zen Browser](https://zen-browser.app) - with [Zen Second Sidebar](https://github.com/k00lagin/zen-second-sidebar/releases/tag/v1.3.2)

To the best of my knowledge, Second Sidebar should work on most, though obviously not all, forks of Firefox.

## Closing

I moved back to Vivaldi when Microsoft announced they were going to retire the sidebar. I tried Whale and loved it, but couldn't get sync to work so I ended up on Vivaldi. That said, Vivaldi is generally very slow for me so I'll probably end up on Floorp. Otter is cool, but its engine is really old.

Sidebars in web browsers aren't for everyone, and the comments in the subreddits I mentioned above should be more than enough to confirm that. Posts complaining about the sidebar being removed are met with comments ranging from confusion and disbelief to disdain and disgust. I multitask a lot, and the sidebar is a great tool to empower my multitasking. Like I said, I don't think I can really use a web browser without one anymore. But Microsoft has a history of abandoning projects and features without explanation, and no one should be surprised that they've done it yet again, especially for a feature used by, probably, a minority of users.

I hope you find this information useful and that, whichever alternative you choose, it serves your needs.
